# Padrão de entrega solicitado

Cada versão deve ser entregue em **um único arquivo ZIP contendo os executáveis compilados e o código-fonte correspondente**. As pastas `executavel/` e `fonte/` ficam no mesmo pacote, acompanhadas de instruções, histórico da versão, testes e hashes. Só separar os pacotes se o usuário pedir explicitamente.
